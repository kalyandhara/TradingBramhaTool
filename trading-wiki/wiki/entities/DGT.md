# DGT (dgtrd)

## What
TradingView Pine Script author, handle **dgtrd**, holding **Pine Wizard** status (TradingView's recognition tier for prolific, high-quality script publishers). Publishes open-source indicators oriented toward structural / Smart-Money-style market analysis (ICT methodology, market structure, multi-timeframe).

## Why it matters here
Same role in this wiki as [[entities/LuxAlgo]] — an indicator author whose open-source scripts serve as *reference implementations* of how the community mechanically defines a primitive, not as proprietary edge. DGT's FVG script is notable for making the **"what counts as a filled gap"** question a first-class user setting (four fill definitions), which directly parameterizes the wick-through-vs-close-through mitigation debate the wiki already tracks on [[concepts/Fair-Value-Gap]].

## Contributions ingested
- [[sources/FVG-DGT-Pine]] (2026-07-22) — "Fair Value Gaps by DGT"; source for the four fill-classification definitions (Any Touch / Midpoint / Wick Sweep / Body Beyond) and the current-TF + HTF + **LTF/intrabar** three-source detection model added to [[concepts/Fair-Value-Gap]].

## Notes
- Not registered financial advice — an indicator author. Scripts are descriptive (mark imbalance zones), explicitly "informational and educational purposes only."
