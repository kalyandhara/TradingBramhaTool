# Source — SwingEdge "What is swing trading?" (Learn series, lesson 1/22)

## Metadata
- **Source type**: Educational article, first lesson in SwingEdge's "Learn" curriculum
- **URL**: https://www.swingedge.info/learn/intro-swing-vs-day
- **Read time**: ~28 min (site's own estimate); tagged Fundamentals, Trading style

## Key Takeaways
- Mostly introductory material already well-covered elsewhere in this wiki (swing vs. day trading distinction, candlestick OHLC basics, single-candle patterns as "footnotes not verdicts" — consistent with [[concepts/Candlestick-Patterns]]'s existing trend-first rule). Filed primarily for the **lesson catalog** below (reference value for future targeted ingests) and one concrete, reusable addition: a **structured review-cadence checklist**.
- **Review cadence framework** (the one genuinely new, reusable item):
  - **Pre-market**: scan watchlist for gap risk, corporate actions, whether key levels are still valid
  - **Post-close**: update journal, mark invalidation levels, decide if tomorrow is a no-trade day based on news/mental state
  - **Weekly**: review win/loss not just in ₹ but in *process* — did you follow entry, size, exit rules?
  - **Monthly**: step back for regime — trending vs. choppy markets favor different setup types
  - This is a concrete, time-boxed habit structure distinct from the more philosophy-level content already in [[analyses/Kalyan-Trading-Philosophy]] — worth treating as the operational/scheduling layer that sits underneath that philosophy.
- Explicit warning against **style-mixing without rules**: "turning a failed swing into an 'investment' to avoid a loss, or scalping a long-term idea because of boredom" — names a specific, common discipline failure mode (rationalizing a stop-loss skip by relabeling the holding period) worth keeping in mind as a concrete red flag to self-check against.
